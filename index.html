02 / La idea detrás del algoritmo

Avisar. Ceder. Entrar de uno en uno.

Dekker coordina dos procesos con dos banderas y un turno. Piensa en dos personas que comparten una máquina.

01 / EL LUGAR

La sección crítica

Es la parte del programa que usa el recurso compartido. En nuestra fábrica, es el momento de usar la máquina.

Regla de oro: máximo uno dentro.
02 / EL AVISO

«Quiero entrar»

Cada proceso tiene una bandera: flag[0] o flag[1].

true → mantiene su intención de entrar.
false → no solicita o ha cedido temporalmente.

La bandera permanece levantada mientras usa la máquina.

03 / EL DESEMPATE

«Tú primero»

Si los dos levantan su bandera, turn indica quién tiene prioridad.

El otro baja su bandera y espera. Al terminar, quien entró cede el turno y baja su bandera.

El turno no obliga a esperar si la otra bandera ya está bajada.

Exclusión mutua significa que nunca hay dos procesos ejecutando la sección crítica a la vez. Pedir entrar no es lo mismo que estar dentro.

Ahora veamos qué pasa cuando ambos quieren entrar.

Ver el pseudocódigo y la instrucción de este paso

Cada proceso ejecuta este código: i es él mismo y j es el otro.

flag[i] = true;
while (flag[j]) {
if (turn == j) {
flag[i] = false;
while (turn == j) { /* espera activa */ }
flag[i] = true;
}
}
// SECCIÓN CRÍTICA: usar la máquina
turn = j;
flag[i] = false;

Modelo didáctico: dos procesos, lecturas y escrituras atómicas y memoria secuencialmente consistente. La espera es activa: el proceso consulta la variable repetidamente.

Los dos terminaron. Nunca compartieron la máquina al mismo tiempo.
Las banderas avisan; el turno desempata.
